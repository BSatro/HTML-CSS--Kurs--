# HTML & CSS – Nauka i Projekty

Repozytorium zawiera materiały, zadania i notatki z kursu [Tworzenie stron WWW w HTML i CSS od podstaw do eksperta](https://www.udemy.com/course/kurs-tworzenia-stron-www-w-html-i-css-od-podstaw-do-eksperta/) na platformie Udemy, a także moje własne projekty ćwiczeniowe.

---

## Struktura repozytorium

* `HTML..Sekcja1-12/` – podstawowe znaczniki HTML, atrybuty, struktura dokumentu oraz praca z multimediami i linkami.
* `CSS..Sekcja13-14/` – selektory, kaskadowość, model pudełkowy (box-model), formatowanie tekstu i podstawy układu.
* `PierwszaStrona..Sekcja15/` – pierwszy kompletny mini-projekt łączący HTML i CSS.

> * `notatki/` – moje podsumowania, ściągi (cheatsheety) i przydatne wskazówki. 

---

## Użyte technologie i narzędzia

* **HTML5** – semantyczna struktura stron
* **CSS3** – stylowanie i układ elementów
* **Visual Studio Code** – środowisko programistyczne
* Rozszerzenie **Live Server** – lokalny serwer deweloperski
