Programowanie stron internetowych



Od zawsze fascynowało mnie, jak działają strony internetowe. Z czasem odkryłem, że mogę je tworzyć samodzielnie, korzystając z HTML i CSS. To moje hobby, które sprawia mi ogromną frajdę i pozwala rozwijać kreatywność. Na tej stronie opowiem, czym jest HTML i CSS, dlaczego lubię programowanie i pokażę moje pierwsze projekty.

Czym jest HTML i CSS?


HTML:

Jest to język, który buduje „szkielet” każdej strony internetowej. Dzięki niemu możemy dodawać nagłówki, akapity, linki, obrazki czy listy.
Przykład:

<h1>Witaj na mojej stronie!</h1> - tym budujemy nagłówek
<p>To jest mój pierwszy akapit.</p> - tym budujemy akapit
<a href="https://google.com">Kliknij tutaj a przeniesie cię na google</a> - tym budujemy link do zewnętrznej strony


CSS:

Odpowiada on za wygląd strony – kolory, czcionki, odstępy, układ elementów. Dzięki CSS zwykły tekst może zamienić się w coś atrakcyjnego wizualnie.
Przykład:

h1 {
color: blue; - zmiana koloru nagłówka
text-align: center; - wycentrowanie nagłówka
font-family: Arial, sans-serif; - zmiana czcionki nagłówka
}
p {
color: #333; - zmiana koloru akapitu
font-size: 18px; - zmiana wielkości liter akapitu
}
